# DECMon

A machine-language "workbench" development environment for the Commodore 64,
written in BASIC V2.

## Files

- `decmon.prg` - DECMon executable/listable BASIC program
- `decmon.d64` - D64 disk image containing `decmon.prg`
- `decmon-readme.txt` - command quick reference
- `decmon-manual.pdf` - full reference manual and development notes
- `decmon.bas` - human-readable BASIC listing

## PETSCII

`decmon.prg` contains literal PETSCII control characters on lines 3210, 3250,
and 11150 which are not reproduced in `decmon.bas`.

Lines 3205, 3245, and 11145 document the PETSCII characters used by the
following lines and show how to type them.
